# 📡 مراقب الشبكة

مراقبة لحظية لشبكات الميكروتيك (MikroTik) من الجوال واللابتوب.

- حالة الإنترنت وموارد الراوتر
- HOST و ACTIVE مع استهلاك كل مستخدم
- المودمات والأكسسات (بنق مستمر + تنبيه عند الانقطاع)
- الواجهات: السرعة اللحظية + الاستهلاك بالجيجا
- سجل الراوتر (LOG) لحظياً مع إشعار فوري للأخطاء الحمراء

## التحميل
من تبويب **Actions** ← آخر عملية ناجحة ← **Artifacts**:
- `NetMonitor-APK` ← للجوال
- `NetMonitor-Windows` ← للابتوب

## المطلوب في الميكروتيك
- تفعيل خدمة `api` من IP → Services (المنفذ 8728)
- مستخدم بصلاحيات: `api, read, test, write`
